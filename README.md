# 카드섹션 시뮬레이터

카드섹션 장면을 미리 보고, 음악에 맞춰 지휘 연습을 할 수 있는 웹사이트예요.
이미지 한 장을 스케치북 수만큼 조각내서 한 장씩 붙여 보여줘요. 줄 사이가 떨어져 있어도 그림이 잘려 사라지지 않고, 모두 붙이면 하나의 그림으로 이어져요. 손이 스케치북 가장자리를 가려서 실제처럼 띄엄띄엄 보여요.

## 폴더 구조

```
card/
├─ index.html          화면
├─ css/style.css       디자인
├─ js/app.js           동작
└─ assets/
   ├─ config.js        기본으로 불러올 이미지·음원 목록, 기본 인원
   ├─ images/          장면 이미지
   └─ audio/           음원
```

## 사용법

- `index.html`을 더블클릭해서 브라우저로 열면 돼요.
- **＋ 이미지 추가**: 여러 장을 한 번에 고를 수 있어요. 파일 이름 순서대로 장면이 추가돼요.
- **＋ 음원 추가**: 곡을 추가하면 바로 선택돼요.
- **이미지 관리**: 장면 순서 바꾸기(▲▼), 삭제(✕), 줄 추가·삭제, 기본값(6·5·6)으로 되돌리기.
- **음원 관리**: 곡 선택, 순서 바꾸기(▲▼), 삭제(✕), 음원 추가.
- **붙여보기**: 간격과 손 없이 스케치북을 모두 붙여서 완성된 그림을 확인해요.
- 무대 오른쪽 **＋ / －**: 줄마다 인원을 바꿔요.
- 하단 바: 장면 앞뒤 이동, 음악 재생·일시정지와 위치 이동, 맞춤 방식, 손 보이기, 전체화면.

### 단축키

| 키 | 동작 |
|---|---|
| ← / → | 이전 / 다음 장면 |
| Home / End | 처음 / 마지막 장면 |
| 스페이스바 | 음악 재생 / 일시정지 |
| F | 전체화면 |

## 기본 이미지·음원 바꾸기

웹사이트에서 직접 올린 파일은 새로고침하면 사라져요. 항상 쓰는 파일은 이렇게 넣어주세요.

1. 이미지는 `assets/images/`, 음원은 `assets/audio/` 폴더에 넣어요.
2. `assets/config.js`를 열고 목록에 경로를 적어요.

```js
window.CARD_CONFIG = {
  rows: [6, 5, 6],
  images: ["assets/images/01.png", "assets/images/02.png"],
  audio: ["assets/audio/song.mp3"]
};
```

> 이미지는 가로:세로가 무대 모양(기본 6·5·6명이면 약 2.7 : 1)과 비슷하면 "늘리기"로 봤을 때 가장 자연스러워요.

## 깃허브에 올리기

1. 깃허브에서 새 저장소를 만들고 이 폴더의 파일을 모두 올려요.
2. 저장소의 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열 수 있어요.
